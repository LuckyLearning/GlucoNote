# 主题与外观（浅色 / 深色 / 跟随系统）

## 1. 三种模式

| 模式 | 枚举 | 行为 |
|---|---|---|
| 跟随系统 | `ThemeMode.SYSTEM` | 系统深色就深色，系统浅色就浅色（默认） |
| 浅色 | `ThemeMode.LIGHT` | 始终浅色，无视系统设置 |
| 深色 | `ThemeMode.DARK` | 始终深色，无视系统设置 |

入口：**我的 → 外观**。切换后立即生效，无需重启，选择写入 DataStore 永久保存。

## 2. 代码链路

```
我的 → 外观（FilterChip）
   │  ProfileViewModel.setThemeMode(mode)
   ▼
SettingsRepository.saveThemeMode(mode)      // 只写 theme_mode 这一个键
   │
   ▼  DataStore("settings") → settingsFlow
MainActivity：collect → 算出 dark: Boolean
   │
   ├─ GlucoNoteTheme(darkTheme = dark)      // Compose 配色 + LocalIsDark
   ├─ WindowCompat.getInsetsController(...)  // 状态栏/导航栏图标明暗
   └─ window.setBackgroundDrawable(...)      // 窗口底色（防止冷启动/转场闪白）
```

关键文件：

| 文件 | 职责 |
|---|---|
| `data/model/ThemeMode.kt` | 枚举 + `fromKey()`（容错：未知值回落到「跟随系统」） |
| `data/model/Settings.kt` | 带上 `themeMode` 字段供界面回显 |
| `data/repository/SettingsRepository.kt` | `settingsFlow` 读取、`saveThemeMode()` 写入 |
| `MainActivity.kt` | 解析模式 → 应用到主题、系统栏、窗口底色 |
| `ui/theme/Theme.kt` | 明暗两套 ColorScheme、圆角、`LocalIsDark` |
| `ui/profile/ProfileScreen.kt` | 「外观」卡片 UI |

## 3. 三个必须同步的地方

主题相关的**颜色常量硬编码在三处**，改配色时必须一起改，否则会出现闪白/闪黑：

| 位置 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `ui/theme/Theme.kt` → `LightColors/DarkColors.background` | Compose 背景 | `#F6FAF6` | `#0F1511` |
| `res/values(-night)/colors.xml` → `window_background` | 窗口底色（冷启动那一帧） | `#F6FAF6` | `#0F1511` |
| `MainActivity.kt` → `LIGHT_BG / DARK_BG` | 强制主题时覆盖窗口底色 | `#F6FAF6` | `#0F1511` |

**为什么窗口底色也要管**：`values-night` 只跟随**系统**深浅色。
用户在浅色系统里选了「深色」，资源层仍然是浅色窗口 —— 冷启动或页面转场的那一帧会闪白。
所以在 `MainActivity` 里按解析后的 `dark` 直接 `setBackgroundDrawable()`。

## 4. 系统栏图标

`enableEdgeToEdge()` 的默认行为是跟随**系统**深色状态，不是应用主题。
所以强制浅色/深色时要手动同步，否则会出现「浅底 + 浅图标」看不见：

```kotlin
WindowCompat.getInsetsController(window, view).apply {
    isAppearanceLightStatusBars = !dark      // 浅色主题 → 深色图标
    isAppearanceLightNavigationBars = !dark
}
```

## 5. 已知边界

- **不会**改动系统设置。`ThemeMode` 只影响本应用，退出应用后系统仍是用户原本的深浅色。
- 没有使用 `UiModeManager.setApplicationNightMode()`（API 31+）：它会让资源层也跟着变，
  但会触发配置变更/界面重建，切换时有一次可见的重启闪烁，收益不值。
- 输入过程中的数值不会被主题切换打断：`ProfileViewModel` 只在**首次**收到设置时
  把数值灌进输入框（`textSeeded` 标记），后续设置变更（例如切主题）不会覆盖正在编辑的内容。

## 6. 想加第四套主题（如「护眼」）时要改哪

1. `ThemeMode` 加枚举值（`key` + `label`）；
2. `Theme.kt` 加一套 `ColorScheme` 与选取分支（`GlucoNoteTheme` 的 `darkTheme` 参数换成
   直接传 `ThemeMode` 更合适）；
3. 「外观」卡片的 `FilterChip` 会自动多出一个（遍历 `ThemeMode.values()`）；
4. 同步 `res/values*/colors.xml` 与 `MainActivity` 的窗口底色。
