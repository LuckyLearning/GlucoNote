# 记一笔：四步引导录入

> 适用范围：新增记录（`AddRecordScreen`）。编辑既有记录仍走单页表单，不受本文约束。
> 最后更新：2026-10-28

## 1. 三条产品决策

2026-10-28 拍板，后续改动请先对照这三条：

1. **点选只高亮，前进必须按底部按钮**。不允许"点一下卡片直接跳下一步"——长者容易误触，也会和底部按钮形成两套前进路径。
2. **时间步保留双滚轮**（时 / 分常驻），不做"折叠进手动调整"。
3. **全站只有「记一笔血糖」一个录入入口**。首页原有的五个时段捷径（跳过第 1 步）已删除，`add/period/{period}` 路由一并移除。

## 2. 四步流程

| 步骤 | 问什么 | 可点 | 前进条件 |
|---|---|---|---|
| 1 状态 | 这次是什么状态？ | 5 张状态卡（单选，按当前钟点打「推荐」角标） | 始终可进（默认预选推荐项） |
| 2 日期 | 哪一天测的？ | 今天 / 昨天 / 选其他日期（日历） | 始终可进（默认今天） |
| 3 时间 | 大概几点测的？ | 「用现在的时间」+ 时/分双滚轮 | 始终可进 |
| 4 血糖值 | 血糖是多少？ | 自绘数字键盘（0-9、`.`、⌫、清空） | 能解析出 > 0 的数值 |

顶部有 `第 N 步 / 共 4 步` 文案 + 4 段进度条（`animateColorAsState` 300ms 跟随）。
进度条下方是**固定高度**的「已选」摘要条（第 1 步显示占位提示），避免切换时把内容顶下去。

## 3. 点击与返回规则

- **唯一闸门**：`AddRecordViewModel.advanceFrom(expectedStep)` / `backFrom(expectedStep)`。
  `expectedStep` 与当前 step 不一致就直接丢弃，因此连点第二下天然无效，不会跳步。
- **底部只有一个主按钮**，文案随步变（下一步 → 确认保存）。"回上一步"只由顶栏箭头和系统返回承担。
- **未保存退出要二次确认**：判定为脏的条件是「填了血糖值 / 改了状态 / 改了时间」。
- **退出只在第 1 步发生**（`backFrom` 返回 true），中途返回都是退回上一步。

## 4. 转场规格

`Motion.wizardForward()` / `Motion.wizardBackward()`，方向由 `targetState > initialState` 判定：

| | 进入 | 退出 |
|---|---|---|
| 前进 | 右移 `width/12` + 淡入 180ms | 左移 `width/24` + 淡出 90ms |
| 后退 | 左移 `width/12` + 淡入 180ms | 右移 `width/24` + 淡出 90ms |

要点：

- **不用 scale**。整屏缩放在低端机上会让文字有"呼吸感"，长者会觉得画面在抖。
- 退出比进入快（90 vs 180），压缩两层都半透明的空档，避免透视出底色。
- `AnimatedContent` 上挂 `contentKey = { it }` + `clipToBounds()`，过渡中再切步不会残留两层、也不会溢出边界。

其它微动效：血糖数字上下翻牌（120/90ms）、数字键按下 `scale 0.96` + 一次轻触感、保存成功弹对勾卡停留 700ms 再退出（替代原来的 Toast）。

## 5. 性能约定（"很卡"的根因与对策）

| 问题 | 对策 |
|---|---|
| 滚轮每过一格就写 ViewModel → 整页重组 | 时/分改为 `GuidedAddScaffold` 内的 `MutableIntState`，**只在离开第 3 步时**一次性 `setHourMinute` |
| 每格都触发震动，快速滑动变"嗡嗡" | `WheelColumn` 内 50ms 节流 |
| 进入第 3 步时首帧就回调一次 | `snapshotFlow{...}.drop(1)` |
| 「用现在的时间」用 `key()` 重建整列（23×21 / 59×21 项） | 改传 `WheelScroll(targetIndex, token)`，内部 `animateScrollToItem` 走最短路径滚过去 |
| 滚轮文本列表每次重组重建 | `remember { (0..23).map { ... } }` |

## 6. 输入规则（`GlucoseInput`）

纯函数，单测见 `GlucoseInputTest`。

- 只有一个小数点；`.` 在空串上自动补成 `0.`
- **最多 1 位小数**（血糖仪读数精度）
- 整数部分最多 3 位
- 去前导零：`0` + `5` → `5`，但 `0.` 保留
- 超出 1.0–50.0 **不阻断**：内联红条提示 + 保存时二次确认弹窗

## 7. 布局与无障碍

- 第 4 步用 `BoxWithConstraints`：按键高度 `clamp(maxHeight/9, 48dp..64dp)`，数字字号在矮屏降到 52sp；整页可竖向滚动。
- 状态卡 / 日期卡用 `Modifier.selectable(role = Role.RadioButton)`，TalkBack 会读"已选中"；选中态额外给一个 ✓。
- 所有可点区域 ≥ 48dp；主按钮 60dp 高、整行宽。
- 校验提示全部内联，不再用 Toast（一闪而过、还挡键盘）。

## 8. 已知取舍

- 小数位固定 1 位：个别用户想记 6.25 会被拒；如确有需要，改 `GlucoseInput.MAX_DECIMALS` 并同步单测。
- 第 3 步滚轮常驻，页面在小屏上略长（已可滚动，不会裁切）。
- 编辑模式保持单页表单，不与本向导复用，避免"改一条也要走四步"。

## 9. 回归清单

手工：

1. 第 1 步连点同一张状态卡 3 下 → 仍停在第 1 步（只有底部按钮能前进）。
2. 一路 `下一步` 到第 4 步，中途顶栏返回逐级回退，第 1 步再返回才退出。
3. 第 3 步快速拨分钟 → 不卡顿、不跳回旧的小时值；点「用现在的时间」滚轮滚过去而不是闪一下。
4. 输入 `00`、`05`、`6.25`、`123` 的边界表现。
5. 填了值后直接返回 → 弹「还没保存」。
6. 小屏 / 横屏 / 系统字体 1.3x 下第 4 步不裁切。
7. 首页只剩一个「记一笔血糖」按钮。

自动：`./gradlew :app:testDebugUnitTest`（`GlucoseInputTest`、`PeriodSuggestionTest`）。
