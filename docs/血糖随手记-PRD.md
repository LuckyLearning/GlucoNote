# 血糖随手记 · 产品需求文档（PRD）

- **版本**：v0.2（草案）
- **日期**：2026-10-26
- **状态**：需求 + 设计阶段（先出需求/原型/设计，开发待确认后启动）
- **平台**：Android 原生 App（Kotlin + Jetpack Compose，本地存储，无后端）

---

## 1. 产品概述

为血糖关注人群（糖尿病/前期人群及代记录家属）提供一款**轻量、隐私、可统计**的血糖记账工具。

- **核心定位**：每日多点测量快速记账 → 形成历史数据 → 统计分析辅助控糖与复诊。
- **数据策略**：默认**本地存储**，不依赖账号与服务器；通过**手动导出/导入 CSV** 完成换机备份。数据不离开手机，除非用户主动导出。
- **单位**：默认 **mmol/L**（全国通用）；mg/dL 切换留作二期。

---

## 2. 用户角色与场景

| 角色 | 说明 |
|---|---|
| 主要用户 | 血糖偏高/糖尿病患者本人 |
| 次要用户 | 家属（代为记录、整理复诊数据） |

**核心场景**
1. 一天内空腹、三餐后、睡前多次测量后，快速逐条记账。
2. 复诊前导出一段时间数据，供医生参考。
3. 长期观察控糖趋势，看达标率是否改善。

**本期不涉及**：医生端、多账号共享、云端协作。

## 3. 功能需求

### 3.1 血糖记录（核心）
录入字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| 测量时间 | 时间 | 默认当前时间，**可点击修改**（系统日期/时间选择器合并） |
| 血糖值 | 数字 | 单位 mmol/L，必填 |
| 测量标签 | 枚举单选（快捷标签） | 空腹 / 早餐后 / 午餐后 / 晚餐后 / 睡前（5 个固定节点；首页快捷按钮与录入选项完全一致） |
| 备注 | 文本（可选） | 自由输入，如「吃了面条」「刚运动完」 |

- **快捷标签说明**：空腹=晨起未进食（建议早餐前）/ 早餐后=早餐后约 2 小时 / 午餐后=午餐后约 2 小时 / 晚餐后=晚餐后约 2 小时 / 睡前=晚间入睡之前。这 5 个标签既作为**首页快捷记录按钮**，也是**录入时的标签选项**，同时是**统计分析的分组维度**（见 §3.2）。
- **列表**：按测量时间倒序；支持**编辑 / 删除（二次确认）**。
- **校验**：数值超出合理范围（如 <1.0 或 >50.0）弹提醒二次确认；血糖值必填。
- **区间着色**：列表与录入页用颜色标注 偏低/正常/偏高（蓝/绿/红），参考当前目标范围。
- **快捷记录**：首页提供 5 个大按钮，一键带出对应标签进入录入（空腹 / 早餐后 / 午餐后 / 晚餐后 / 睡前），与录入页标签选项完全一致。

### 3.2 统计与分析
- **趋势图**：日 / 周 / 月 / 年 视图切换；折线展示血糖随时间变化，每个数据点**标注具体数值标签**；叠加目标区间参考线/阴影带；支持按标签筛选（全部 / 某标签）。
- **达标率**：按 5 个标签（空腹 / 早餐后 / 午餐后 / 晚餐后 / 睡前）**分别**统计达标率，环形图 + 各标签进度条展示；目标范围**可自定义**。
- **年月日区间分析**：提供「日 / 月 / 年」时间粒度切换，按所选粒度把记录自动分桶（日=自然日、月=自然月、年=自然年），每个时间桶展示 **均值、最高、最低、达标率**，并以列表/柱状呈现；可与标签筛选联动，便于对比「本月各天」「今年各月」的控糖走势。
- **区间统计**：近 7 天 / 30 天 / 自定义时间段的整体平均值、最高、最低、标准差；支持按标签筛选查看。
- **标签筛选**：统计页提供「全部 / 空腹 / 早餐后 / 午餐后 / 晚餐后 / 睡前」切换，趋势图、区间分析与区间统计随筛选联动（达标率始终按 5 个标签分别展示，便于横向对比同一目标下的差异）。
- **概览卡片**：今日已记录次数、最近一次数值、近 7 天平均。

### 3.3 导出与导入
- **导出**：全部记录生成 **CSV**（时间 / 数值 / 时段 / 备注，UTF-8 BOM 兼容 Excel），通过系统文件选择器（SAF）保存或分享。
- **导入**：通过系统文件选择器（SAF）打开 CSV 备份恢复（用于换设备迁移），解析后合并。
- 导出前提示「请确认已包含全部记录」。

### 3.4 设置
- 自定义目标血糖范围（空腹 / 餐后，默认参考临床常用值，见 §10）。
- 关于页 + 免责声明（数据仅供参考，不替代医嘱）。

## 4. 非功能需求

| 维度 | 要求 |
|---|---|
| 持久化 | Room 本地数据库；卸载前提示先导出备份 |
| 性能 | 1000+ 条记录下图表与列表流畅 |
| 隐私 | 数据不离开手机，除非用户主动导出 |
| 易用性 | 大按钮、大字体，适配中老年用户快速录入 |
| 兼容 | Android 8.0+（API 26）；竖屏手机为主 |
| 权限 | 仅导出/导入时通过 SAF 访问存储，无需申请危险权限 |

## 5. 数据模型

本地存储：记录用 **Room**（SQLite），设置用 **DataStore**（键值）。

```
GlucoseRecord (Room @Entity)
  id: String            // UUID 主键
  measureTime: Long     // 测量时间戳(ms)
  value: Float          // 血糖值 mmol/L
  period: String        // 标签 key: fasting|breakfast|lunch|dinner|sleep
  note: String          // 备注
  createdAt: Long       // 创建时间戳(ms)

Settings (DataStore)
  fastingMin / fastingMax: Float     // 空腹目标范围
  postprandialMax: Float             // 餐后目标上限（参考：<10.0）
```

## 6. 页面结构与导航

单 Activity + Compose Navigation；底部 **NavigationBar** 切换四个一级页面：

| 页面 | 内容 |
|---|---|
| 首页 Home | 今日概览卡片 + 快速记录入口（5 大按钮）+ 最近记录 |
| 记录 Records | 录入表单（时段+时间+数值+备注）+ 历史记录时间线（编辑/删除） |
| 统计 Stats | 趋势图 + 达标率环形 + 区间统计（日/周/月切换） |
| 我的 Profile | 目标范围设置、导出/导入、关于与免责 |

## 7. 技术选型

| 项 | 方案 |
|---|---|
| 语言 | Kotlin 100% |
| UI | Jetpack Compose + Material3 主题 |
| 架构 | MVVM + 单向数据流（UDF） |
| 本地存储 | Room（记录） + DataStore（设置） |
| 异步 | Kotlin 协程 + Flow |
| 图表 | Compose Canvas 自绘（折线 + 环形），零第三方依赖 |
| 导出/导入 | Storage Access Framework (SAF) + CSV 纯逻辑解析 |
| 导航 | Compose Navigation |
| 最低版本 | API 26（Android 8.0），compile/target API 34+ |
| 依赖注入 | 轻量（Application 持有单例 Repository，ViewModel 经 factory 获取），不引入 Hilt |

## 8. 范围管理

**本期做**：本地记录/列表/编辑删除、趋势图（含数据点数值）、达标率、区间统计、CSV 导出导入、目标范围设置。

**二期（本期不做）**：
- 多设备云同步 / 账号体系
- 饮食 / 用药 / 运动上下文标签
- 通知提醒（每日测量提醒）
- 单位切换（mmol/L ↔ mg/dL）

---

## 9. 验收标准（草案）

1. 能完整录入一条标准记录（时间/数值/时段/备注），落盘后可重开查看。
2. 列表区间着色与目标范围一致。
3. 趋势图在日/周/月/年切换下数据正确，**折线每个数据点显示对应数值标签**；达标率按 5 个标签计算正确；**年月日区间分析在切换日/月/年粒度时分桶与均值/达标率计算正确**。
4. 导出的 CSV 可被 Excel / 记事本正确打开，字段完整；导入可还原记录。
5. 1000+ 条数据下列表与图表无明显卡顿。
6. 在 Android 8.0+ 真机/模拟器上安装运行正常，底部导航四页切换流畅。
