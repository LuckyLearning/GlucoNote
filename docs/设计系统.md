# 血糖随手记 · 设计系统（GlucoNote Design System）

- **版本**：v1.0（草案，承接现有 Compose 主题）
- **日期**：2026-10-27
- **平台**：Android 原生（Kotlin + Jetpack Compose + Material3），竖屏手机为主，Android 8.0+（API 26）
- **风格**：简约现代 / 医疗绿 + 薄荷中性 / 适老优先
- **配套**：[`ui-prototype-v2.html`](ui-prototype-v2.html)（可交互高保真原型，含浅/深主题切换）

> 本系统基于工程已落地的 `ui/theme/Color.kt`、`Theme.kt`、`res/values(-night)/colors.xml` 提炼与扩展，给出**统一令牌、组件规范、无障碍与开发对接**。新增令牌均标注 Compose 落点，确保设计→代码一致。

## 0. 设计原则

| # | 原则 | 说明 |
|---|---|---|
| 1 | 安静可信（Calm & Trustworthy） | 医疗场景不制造焦虑：绿色为主调，红色**仅**用于真正偏高的读数；危险用"偏高 + 红 + 文字"三重提示，而非闪烁。 |
| 2 | 一目了然（At a glance） | 关键血糖读数用**大字号 + 色彩 + 文字标签**三重编码，老人/弱光环境也能秒懂偏低/正常/偏高。 |
| 3 | 大而易触（Big & Tappable） | 触控目标 ≥ **48px**（高于 Material 基准 44px）；主操作常驻拇指热区；数值输入用大键盘、大字号。 |
| 4 | 一致克制（Consistent & Restrained） | 单一主色、统一圆角（10/16/24/28）与 4px 间距栅格；组件高度复用，杜绝视觉碎片化。 |
| 5 | 明暗皆可（Adaptive） | 浅 / 深 / 跟随系统三态；配色在 `Theme.kt`、`colors.xml`、`MainActivity` 三处强制同步，避免冷启动闪白/闪黑。 |

## 0.1 导航结构（信息架构 IA）

| 页面 | 角色 | 是否含「新增记录」 |
|---|---|---|
| 首页 Home | 概览 + 5 个**快捷记录**按钮（唯一新增入口） | 否（仅触发跳转） |
| 记一笔 Add | 独立录入页（由首页快捷按钮进入） | **是**（表单） |
| 记录 Records | 历史记录时间线（查看 / 编辑 / 删除） | **否** |

| 我的 Profile | 目标范围 / 数据 / 外观 / 关于 | 否 |

> **关键规则**：新增记录功能**只**在「首页快捷按钮 → 记一笔独立页」；**「记录」页仅展示历史**，不含录入表单。理由：① 避免与首页入口重复、降低中老年用户认知负担；② 与工程实际一致——`AddRecordScreen` 由 `add/period/{period}` 路由进入，记录页无新增 FAB。

## 2. 字体系统（Typography）

- **字体族**：中文 `PingFang SC` → `Microsoft YaHei` → `system-ui`；英文/数字 `Roboto` → `system-ui`。Compose 用 `Typography` 默认 + 中文回退。
- **基准**：正文 ≥ **16sp**（适老），关键读数 ≥ **28sp**。
- **字重**：400（常规）/ 500（中）/ 600（半粗）/ 700（粗，仅大读数）。

| Token | 用途 | 字号 | 行高 | 字重 |
|---|---|---|---|---|
| `display` | 主血糖读数 | 32sp | 1.1 | 700 |
| `headline` | 页面标题 | 22sp | 1.2 | 600 |
| `title` | 卡片标题 / 区块名 | 17sp | 1.3 | 600 |
| `subtitle` | 次级标题 | 15sp | 1.4 | 600 |
| `body` | 正文 | 16sp | 1.5 | 400 |
| `body-strong` | 强调正文 | 16sp | 1.5 | 500 |
| `label` | 标签 / 按钮 | 16sp | 1.0 | 600 |
| `caption` | 辅助说明 | 13sp | 1.4 | 400（onSurfaceVariant） |

- **基准单位 4px**；移动端内容边距 `16px`（卡片内 `16px`，页边 `16px`，大区块 `24px`）。

## 5. 动效（Motion）

- **时长**：fast 150ms / normal 300ms / slow 500ms（已在 `Motion.kt`）。
- **缓动**：standard（进出）→ `FastOutSlowIn`；decelerate（进入）→ `linearOutSlowIn`；accelerate（退出）→ `fastOutLinearIn`。
- **页面转场**：fade（避免滑动露底闪白，见 `Theme.kt` 的不透明 Surface 兜底）。
- **尊重无障碍**：`reduceMotion` 开启时仅保留 opacity，去掉位移/缩放。

## 6. 组件库（Components）

> 每个组件给出：用途、结构、状态、最小触控尺寸、令牌映射。组件文件名对应现有 `ui/components/*`。

### 6.1 血糖读数徽标（GlucoseValueBadge）★核心
- **结构**：大数字（`display` 32sp）+ 单位 `mmol/L` + 状态文字（正常/偏高/偏低）+ 方向箭头；底色为状态色 @8% 的圆角胶囊。
- **状态**：正常（绿）/ 偏低（蓝）/ 偏高（红），三态同构仅变色变字。
- **无障碍**：文字与颜色双重编码；`contentDescription` 含 "6.2，正常"。
- 落点：`statusColor()`（Theme.kt）。

### 6.2 快捷记录按钮（QuickRecordButton）★首页核心
- 5 个固定标签（空腹/早餐后/午餐后/晚餐后/睡前），**2 列网格**；每键含：图标 + 名称 + 一行说明 + 迷你状态点（最近一次是否达标）。
- 最小高 **64px**，圆角 `md`，底色 `primaryContainer`；按压 `primary-600` 描边。
- 点击 → 带该标签进入录入页。

### 6.3 时段选择芯片（PeriodChips）
- 复用 5 标签；每片含名称 + 说明；单选高亮（`primary` 描边 + `primaryContainer` 底）。
- 最小高 **48px**，圆角 `sm`。
- **落点**：仅用于「记一笔」独立录入页（由首页快捷按钮进入）；**记录页不含该表单**。

### 6.3.1 记录页·固定悬浮筛选条（RecordsFilterBar）★新增
- **位置**：「记录」页说明卡之下、历史记录列表之上；`sticky` 钉在顶部栏下方——**固定悬浮，不随下方内容滚动**。
- **构成**：「全部」+ 5 时段标签（空腹/早餐后/午餐后/晚餐后/睡前），横向单行排布，超出可横滑（隐藏滚动条）；每片含迷你状态点 + 名称（与首页快捷按钮同色映射）。
- **形态**：胶囊形，最小高 **48px**，默认 `surface` 底 + `outlineVariant` 描边，选中 `primaryContainer` 底 + `primary` 描边；条底为页面背景色并带分隔线，保证列表从其下方滚过时不透底。
- **行为**：单选筛选历史记录；选中某时段仅显示该时段记录，无匹配时展示空态「该时段暂无记录。」；「全部」恢复完整列表。

### 6.4 概览卡片（StatCard）
- 首页三连：今日记录数 / 最近一次 / 近 7 天均值；数字 `headline` 22sp + 标签 `caption`。
- 最近一次带状态色徽标。

### 6.5 区块卡片（SectionCard）
- 默认容器：白 `surface` + 圆角 `md` + `elev-1`；标题 `title` 17sp + 可选"查看全部"。

### 6.6 按钮（Button）
| 变体 | 底色 | 文字 | 最小高 | 用途 |
|---|---|---|---|---|
| Primary | `primary` | `onPrimary` | 48px | 保存、主操作 |
| Secondary | `primaryContainer` | `onPrimaryContainer` | 48px | 次操作 |
| Ghost | 透明 + `primary` 描边 | `primary` | 48px | 导入、取消 |
| Danger | `error` 容器 | `error` | 48px | 删除（二次确认） |

### 6.7 输入框（TextField）
- 时间（点击唤起 `WheelTimeDialog`）、数值（大键盘、`display` 字号回显）、备注（多行）。
- 描边 `outlineVariant`，聚焦 `primary`；校验失败 `error` 描边 + 文字。

### 6.8 分段控件（SegmentedControl）
- 用于统计页"全部/各标签"与"日/周/月/年"切换；选中项 `primary` 底白字，未选 `surfaceVariant` 底。
- 项最小高 **40px**，整体圆角 `sm`。

### 6.9 底部导航（BottomNavigation）
- 4 项（首页/记录/统计/我的），选中 `primary` 图标+文字，未选 `onSurfaceVariant`；高 **80px**（含安全区），图标 24 + 文字 12。

### 6.10 图表组件（Canvas 自绘，零依赖）
- **趋势折线**：x=时间、y=血糖；折线 `chartLine` + 每点 `value` 文本标签（大屏避免重叠可隔点标注）；目标区间半透明 `chartBand` 阴影带 + 上下虚线。
- **达标率环形**：`drawArc` 按 5 标签占比分段，中心百分比；下方各标签进度条（`正常`绿/`偏高`红/`偏低`蓝）。
- **区间柱状**：各时间桶均值柱状 + 达标率文字。

### 6.11 对话框（Dialog）
- 删除确认（Danger 按钮）、数值越界二次确认（`<1.0` 或 `>50.0`）、未保存退出。圆角 `lg`，`elev-2`。

### 6.12 空 / 错 / 加载态
- 空：图标 + "还没有记录，去首页点「记一笔」添加" + 主按钮。
- 加载：骨架屏（卡片占位 `surfaceVariant` @脉冲）。
- 错误：图标 + 说明 + 重试。

### 6.13 记一笔录入页（AddRecordScreen）★新增独立页
- 由首页快捷按钮经 `add/period/{period}` 路由进入；**不在「记录」页内**（见 §0.1）。
- 结构：测量时间（点击唤起 `WheelTimeDialog`）→ 时段选择芯片（预选对应标签）→ 血糖值大字号输入 → 备注 → 保存 / 取消。
- 校验：数值越界（`<1.0` 或 `>50.0`）弹二次确认；为空 / `≤0` 提示。
- 取消返回首页；保存后落盘并返回。

## 7. 适老无障碍规范（Accessibility）

| 维度 | 要求 | 落点 |
|---|---|---|
| 触控目标 | ≥ 48px（快捷键 64px） | 全局 |
| 字号 | 正文 ≥16sp、读数 ≥28sp；支持系统字体放大至 200% | Typography |
| 颜色 + 文字 | 状态三态均有文字/箭头，不靠颜色 alone | GlucoseValueBadge |
| 对比度 | 正文 ≥4.5:1、大字 ≥3:1（已实测通过） | §1.5 |
| 焦点 | 所有可交互有可见 focus 环（`primary` 2px offset 2） | Material3 默认 |
| 朗读 | 关键读数/按钮带 `contentDescription`（中文） | Compose `semantics` |
| 动效 | 尊重 `reduceMotion` | Motion |
| 导航 | 底部 4 项常驻，单手可达；无隐藏手势 | BottomNavigation |

## 8. 主题：浅 / 深 / 跟随系统

- 三态由 `ThemeMode`（SYSTEM/LIGHT/DARK）经 `SettingsRepository` → `MainActivity` 解析为 `dark: Boolean`，传入 `GlucoNoteTheme(darkTheme=...)`。
- **三处配色必须同步**（冷启动/转场不闪）：
  1. `ui/theme/Theme.kt` 的 `background`（`#F6FAF6` / `#0F1511`）
  2. `res/values(-night)/colors.xml` 的 `window_background`
  3. `MainActivity.kt` 的 `LIGHT_BG / DARK_BG`（强制主题时覆盖窗口底）
- 系统栏图标：`isAppearanceLightStatusBars = !dark`，强制深浅时手动同步。
